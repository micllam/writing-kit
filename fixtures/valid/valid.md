# Valid

There is no expiry in the record, and there are no keys with that prefix. The
worker does not retry a failed task. The record contains the key, the value and
the expiry.

The scan reads the keys in order, and the hook reports each alert. The worker
retries once, or the queue requeues the task.

A backticked span such as `should`, `rather than` or `holds` is code. A
cherry-pick copies a commit, and the worker picks up the next task.
